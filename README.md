
# 📊 HR Analytics Dashboard | Microsoft Excel

## 📌 Project Overview

This project focuses on analyzing Human Resources (HR) data
and presenting meaningful insights through an interactive
dashboard built using Microsoft Excel.

The dashboard helps explore workforce demographics,
employee distribution, HR trends, and other key performance
indicators.

## 🎯 Project Objectives

- Analyze employee data.
- Understand workforce demographics.
- Explore employee distribution across departments.
- Identify workforce trends and patterns.
- Present HR insights through interactive visualizations.
- Support data-driven HR decision-making.

## 🛠️ Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Data Cleaning
- Data Visualization
- Slicers and Interactive Filters (if used)
